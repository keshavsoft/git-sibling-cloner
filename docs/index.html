Fast, fail-safe shallow-cloning of Git repositories side-by-side as siblings from any Source of Truth manifest.

$npx git-sibling-cloner <manifest.json> [destination]

Why We Built This

Standard git clone commands can hang indefinitely when dealing with dead remotes, missing repos, or interactive terminal credential prompts. If you're building multi-repo workspaces or cloning 20 dependencies at once, a single frozen clone blocks your entire toolchain.

git-sibling-cloner is designed specifically for dependable, automated sibling workspace cloning:

⚡ 25s Fail-Safe Timeout

Each repository clone is bounded by a strict timeout (configurable). A dead server or private repository will never freeze your command.

🛑 Process-Tree Termination

When a clone times out, it kills the entire process tree using taskkill /pid /T /F on Windows and SIGKILL on POSIX, leaving zero zombie locks.

🔒 Prompt Suppression

Runs with GIT_TERMINAL_PROMPT=0 and GIT_ASKPASS=echo to instantly reject interactive username/password prompts.

⏩ Incremental Skips

Safely checks destination folders before cloning. Repositories already present on disk are skipped in 0ms, making reruns instant.

Input Manifest Format

Accepts a clean JSON array of repository specifications:

[
  {
    "folder": "express",
    "cloneUrl": "https://github.com/expressjs/express.git"
  },
  {
    "folder": "accepts",
    "cloneUrl": "https://github.com/jshttp/accepts.git"
  }
]

Usage Examples

# 1. Clone into current directory from a manifest file
npx git-sibling-cloner repos.json

# 2. Clone into a dedicated folder
npx git-sibling-cloner repos.json ./workspace

# 3. Stream manifest directly via standard input (UNIX pipe)
cat repos.json | npx git-sibling-cloner ./workspace

UNIX Composable Pipeline

Pair seamlessly with npm-repo-resolver to discover and clone in a single command: 

npx npm-repo-resolver express | npx git-sibling-cloner ./express-sources
